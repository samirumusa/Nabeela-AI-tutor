# Curriculum Specification

## Structure
CEFR level -> units -> daily lessons -> learning targets -> activities -> required conversation mission -> evidence/review.

Initial commercial content should be proprietary Nabeela curriculum; a practical first release is a focused A1 course before expanding upward.

## Daily learning loop
**Learn -> Listen -> Speak -> Practice -> Apply -> Test -> Reward**

Preliminary daily learning-item targets:
- 8-10 words
- 3-5 collocations
- 3-5 chunks
- 1-2 sentence patterns

Items should recur across listening, pronunciation, exercises, the speaking mission and spaced review.

## Learning item types
- Word: `decision`
- Collocation: `make a decision`
- Chunk: `I haven't decided yet.`
- Pattern: `I'd like to ___`

## Scenarios
Everyday life, family, numbers/time, market, food, transport, work, interviews, travel, health, banking, presentations and support conversations.

## Content pipeline
CEFR map -> content drafting/generation -> validation -> teacher review -> exercises/dialogues -> audio generation -> publishing -> analytics/revision.
