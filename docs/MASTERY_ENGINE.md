# Mastery Engine

## Principle
Nabeela separates **curriculum position** from **estimated ability by skill**. Example: learner may be on B1 Day 16 while productive grammar remains A2 and listening is B1.

## Skill dimensions
Grammar, vocabulary, listening, speaking, comprehension, fluency and pronunciation (once reliable pronunciation scoring exists).

## Learning-item mastery
Track recognition separately from productive recall. Suggested states:
`New -> Learning -> Familiar -> Recall -> Mastered -> Review Due`

Evidence can include recognition, meaning, pronunciation, correct guided usage, productive recall, spontaneous use and delayed retention.

## Promotion
Do not use an LLM's single judgment or XP total. Promotion should require configured curriculum completion, required conversations, skill thresholds, learning-item requirements, repeated evidence across days and a final challenge. Thresholds must be validated against curriculum goals and human teacher ratings before being presented as authoritative CEFR judgments.
