# Gamification Specification

## Rule
Reward real English learning, not tapping. **Activities -> XP/coins/badges/streaks; evidence -> mastery -> CEFR.**

## Mechanics
- Daily mission stars: Completed / Strong / Mastered
- XP and coins
- Learning streaks (speaking, vocabulary, listening)
- Word Vault states
- Language-set badges
- Side quests
- Level boss challenges
- Skill progress bars

## Example mission
`Survive the Market`: learner has a budget, must buy specified goods, use target vocabulary/chunks, ask prices, negotiate, and sustain meaningful conversation.

Hausa assistance is never punished. If Hausa is used to explain a concept, require a subsequent English retry before awarding mastery evidence.
