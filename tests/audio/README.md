# ASR Benchmark Audio
Store local test recordings here only when appropriate. Avoid committing personal voice recordings by default. Maintain a manifest with expected transcript, language class and intentionally incorrect learner forms that must be preserved.

The active versioned manifest and evaluation instructions are in
[`backend/benchmarks/`](../../backend/benchmarks/README.md). Its default audio paths
resolve to `backend/benchmarks/audio/`; use those paths for the baseline recordings.
